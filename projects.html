NeRF-inspired Seismic Subsurface Imaging

Neural Rendering · Seismic Imaging · Tokenization · Transformer Architecture

A research project on transferring Neural Radiance Fields (NeRF) ideas from multi-view camera rendering to marine seismic acquisition. Offset and azimuth are treated as view parameters in a NeRF-like formulation, and the network learns subsurface reflectivity as a continuous neural field.

Proposed Architecture: An end-to-end tokenized seismic rendering pipeline. Seismic traces are first transformed into time–frequency representations (spectrograms / scalograms), then discretized via vector quantization into compact token sequences. A transformer-based decoder reconstructs CMP-level subsurface structure by learning cross-offset consistency through attention, analogous to how NeRF learns cross-view consistency in 3D rendering. This design enables generalization across different acquisition geometries and handles sparse or irregular sampling.

The tokenization methodology builds directly on the Multimodal Audio Tokenizer project: both seismic traces and audio signals are 1-D time-series with rich spectral structure, so the same vector-quantized encoding and codebook learning techniques transfer naturally.

Tool Selection for Robotic Manipulation

Robot Learning · Affordance · Dexterous Manipulation

Affordance-guided tool selection for dexterous robotic manipulation. The system learns to identify which object to grasp and how to use it based on visual affordance cues, enabling a robot arm to reason about object properties and task requirements before acting.

Part of ongoing research at NYU CILVR, advised by Lerrel Pinto and Irmak Guzey.

PPO-MAML for Meta-World Assembly-v3 (Developed Version coming on 25 Feb!)

Reinforcement Learning · Meta-RL · Robotic Manipulation

A compact PyTorch implementation that combines Model-Agnostic Meta-Learning (MAML) with a PPO inner loop on the Meta-World ML1 assembly-v3 benchmark. The goal is fast policy adaptation for a robotic arm under task variations.

  • Single ~200-line script with fixed seeds, CSV logging, and GIF rollouts.
  • Stable PPO updates using clipping, entropy regularization, and gradient clipping.
  • Runs on CPU (MacBook Pro M2), easily portable to GPU.

Domain-Invariant Racer

Reinforcement Learning · Domain Randomization · Sim-to-Real

A PPO-based racing agent trained under heavy visual and physics randomization. Instead of memorizing a single environment, the policy learns domain-invariant representations that remain stable under changing textures, lighting, and noise.

The project focuses on robustness analysis and attention visualization to understand which parts of the observation space the agent relies on as conditions degrade.

Safe Swarm Control with HOCBFs

Multi-Agent Systems · Control · Safety · Control Barrier Functions

A study of safety-critical control for multi-agent systems using High-Order Control Barrier Functions (HOCBFs). I compare centralized safety filtering for double-integrator dynamics with decentralized, distributed CBF formulations. I used CVXPY for optimization.

The focus is on guaranteeing collision avoidance while minimally modifying nominal control inputs, highlighting the trade-offs between centralized and decentralized safety enforcement.

Multimodal Audio Tokenizer

Audio Representation Learning · Tokenization · Multimodal ML

A research-oriented project exploring how raw audio signals can be converted into compact, discrete token representations suitable for multimodal learning setups. The goal is to bridge continuous audio waveforms with sequence-based models in a way that is efficient, expressive, and reusable across tasks.

The tokenizer is designed as a modular pipeline, making it easy to plug audio tokens into downstream models such as transformers, multimodal encoders, or generative architectures alongside text or vision tokens.

This project also serves as a foundation for the Seismic Subsurface Imaging work: the vector-quantized encoding and codebook learning techniques developed here for audio waveforms transfer directly to seismic trace tokenization, since both are 1-D time-series with rich spectral structure.

Code and experiments: GitHub repository

Image Restoration · Swin Transformer

Implemented and trained SwinIR for single-image super-resolution. Trained on LSDIR and evaluated on Manga109 (×2), achieving ~36.18 dB PSNR and outperforming a CNN baseline (RCAN).
